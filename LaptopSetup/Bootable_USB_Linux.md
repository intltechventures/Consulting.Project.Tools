
# Bootable USB Linux Resources

## Introduction   

My primary laptop OS is Windows 11. As an emergency option, I liked to carry a bootable USB with Linux installed on it.    
   
Why?      
- In case my Windows OS is compromised, or corrupted. 
- In case there is a nation-state attack against Microsoft Windows operating systems. 
- As a prophylactic layer of defense against potential cybsersecurity attacks, when I may need to do Due Diligence on suspicous companies, web sites, etc.
