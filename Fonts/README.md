## Tips

- **Installing Fonts**:   
  + https://fonts.google.com/knowledge/using_type/installing_and_managing_fonts
  + **Windows**:
    * On Windows, the location is ```C:\Windows\Fonts```.
    * If you can’t move fonts there, use ```C:\Users\Username\AppData\Local\Microsoft\Windows\Fonts\``` to install fonts that can only be accessed by your own username.
  + **Mac**:
    * Double-click the font file and click Install Font in Font Book.
  + **Linux**:
    * Copy the font files to your ```~/.local/share/fonts``` or ```/usr/share/fonts directory```.
